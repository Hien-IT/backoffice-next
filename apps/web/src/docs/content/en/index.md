This documentation describes Backoffice: how to use the app, the API and the server's configuration variables. It ships
with the version of the app you are using, so it always matches that version.

## The three parts of the documentation

- **Guides**: how to do each task in the app, step by step, with screenshots.
- **API**: one page per group of endpoints, with parameters, responses and example calls.
- **Configuration**: the environment variables the server reads, grouped, with their default values. Start at the
  [General](/docs/configuration/general) page.

## Finding your way

1. Pick a page in the menu on the left. On a narrow screen, open the menu with the button in the top corner.
2. Use the **On this page** column on the right to jump to a section of the page. This column is only shown on wide
   screens.
3. The end of each page links to the previous and the next page.

## Sharing a link to a section

Hover over a heading, or reach it with the Tab key, then click the `#` sign next to it: a link to that exact section is
copied. The person who opens the link signs in if needed and lands right on that section.

> [!NOTE] The documentation is only available after signing in. It contains no passwords, tokens or internal addresses.
