# Developer Handoff Checklist

## Tokens
- [ ] Primary palette approved.
- [ ] Font family and type scale approved.
- [ ] Source values mapped to semantic tokens.
- [ ] CSS variables imported once.
- [ ] Tailwind v3 theme merged without removing existing config.

## Components
- [ ] Props, emits and slots reviewed.
- [ ] Default, hover, focus, active, disabled, loading and error states covered where relevant.
- [ ] Reka UI exports verified against installed version.
- [ ] Duplicate components and domain-specific patterns reviewed.

## Product UI
- [ ] Current vs historical screens identified.
- [ ] Desktop flows visually compared to Figma.
- [ ] Empty/error/edge cases reviewed.
- [ ] Keyboard accessibility checked.
- [ ] Mobile behavior documented for later phase.

## Release
- [ ] Visual regression reviewed.
- [ ] No token removed while referenced.
- [ ] Product/design approved refactor proposal.
